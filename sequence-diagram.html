EcoSmart Open Marketplace Sequence Diagrams

The Mermaid source below shows how information moves among the users, app, server/database, email service, and wallet/payment provider.

Main flow: verified recycler, generator listing, and funded final-offer payout

sequenceDiagram
    autonumber
    actor Generator as User: Waste generator
    actor Recycler as User: Recycler
    actor Admin as User: EcoSmart administrator
    participant App as Screen/App
    participant Server as Server
    database DB as Server/Database
    participant Email as Email service
    participant Pay as Wallet/Payment provider

    Recycler->>App: Create recycler account; submit verification details and area
    App->>Server: Submit recycler application
    Server->>DB: Save profile as Pending approval
    Admin->>App: Review and approve recycler profile
    App->>Server: Approve profile
    Server->>DB: Set status to Verified
    Recycler->>App: Set accepted materials, price/unit, and availability
    App->>Server: Save catalogue and availability
    Server->>DB: Store recycler matching details

    Generator->>App: Create account; submit name and email
    App->>Server: Request email verification
    Server->>Email: Send one-time email code
    Email-->>Generator: Deliver email code
    Generator->>App: Enter code and area/neighbourhood
    App->>Server: Verify and save profile
    Server->>DB: Save verified generator email and area
    Generator->>App: Scan/upload item or choose material
    App->>Server: Submit intake and area
    Server->>DB: Check catalogue and guidance
    DB-->>Server: Supported material and recycling tip
    Server-->>App: Show guidance

    Generator->>App: Request matching recyclers
    App->>Server: Send selected material and area
    Server->>DB: Find Verified + Available recyclers matching area/material
    DB-->>Server: Profiles, estimates, units, availability
    Server-->>App: Return matching recyclers
    Generator->>App: Select recycler and create listing
    App->>Server: Create listing for selected recycler only
    Server->>DB: Save listing as Sent to recycler
    Recycler->>App: Accept request and agree handover
    App->>Server: Record response and arrangement
    Server->>DB: Save acceptance and timestamp
    Server-->>App: Reveal approved contact details
    opt Matched parties use optional in-app chat
        Generator->>App: Send message about active listing
        App->>Server: Save and deliver message
        Server->>DB: Store message against listing
        Server-->>App: Deliver message to recycler
    end
    opt Matched parties start optional in-app call
        Generator->>App: Start call for active listing
        App-->>Recycler: Present call invitation
    end
    Note over Generator,Recycler: Direct pickup/drop-off occurs outside EcoSmart.

    Recycler->>App: Record actual weight and final amount
    App->>Server: Create pending final offer
    Server->>Pay: Fund exact final-offer amount
    Pay-->>Server: Funding confirmed
    Server->>DB: Save funded offer and 24-hour expiry
    Server-->>App: Show final offer to generator
    Generator->>App: Accept final offer
    App->>Server: Record acceptance
    Server->>Pay: Release full amount to generator
    Pay-->>Server: Payout confirmed
    Server->>DB: Mark Completed; no commission
    Server-->>App: Show time-stamped record

    Admin->>App: Manage materials, profiles, and records
    App->>Server: Save change or retrieve records
    Server->>DB: Update catalogue/profile or return records

Exception flow: unsupported or uncertain material intake

sequenceDiagram
    autonumber
    actor Generator as User: Waste generator
    participant App as Screen/App
    participant Server as Server
    database DB as Server/Database

    Generator->>App: Scan or upload an item
    App->>Server: Submit image for pilot material intake
    Server->>DB: Compare against supported catalogue
    DB-->>Server: No confident supported-material match
    Server-->>App: Return manual-selection fallback
    App-->>Generator: Ask generator to choose a supported material
    alt Generator chooses a supported material
        Generator->>App: Select material manually
        App->>Server: Save selected material
        Server->>DB: Record intake attempt and selection
        Server-->>App: Show guidance and continue to matching
    else Generator cannot choose a supported material
        Server-->>App: Return Not supported in this pilot
        App-->>Generator: Show unsupported-item outcome; no listing
        Server->>DB: Record unsupported intake attempt
    end

Other required decision outcomes

  • If the selected recycler declines, the generator sees other matching recyclers; the listing is not broadcast automatically.
  • If the generator rejects a funded final offer, or does not respond within 24 hours, the server records Rejected or Expired and makes no payout.
  • Recycler prices are estimates only; the funded final offer after inspection is what the generator accepts or rejects.
  • Price history and in-app calls are later optional features. Universal AI identification, unsupported materials, commissions, waste transport/storage, and ownership/dispute decisions are outside this pilot.

Coverage: FR-01–FR-17 are represented in the main and exception diagrams; FR-18 is the optional chat exchange in the Markdown diagram; FR-19–FR-21 are explicitly recorded above.
